# Web音声比較ラボ 評価ルーブリック

## 評価軸
- `自然さ`
- `読み`
- `復唱精度`
- `受付らしさ`
- `被せ耐性`

## スコア
- 1: 実用に足りない
- 2: かなり不自然
- 3: 使えるが粗い
- 4: 十分良い
- 5: 現場投入可能

## 自然さ
- 1: 機械的で会話にならない
- 3: 意味は通るが間が不自然
- 5: 相づち、間、言い回しが自然

## 読み
- 1: 日付、電話番号、医院名の読み崩れが多い
- 3: たまに崩れるが許容範囲
- 5: 数字、記号、固有名詞が安定して読める

## 復唱精度
- 1: 復唱時に数字や日時が頻繁に崩れる
- 3: 一部の項目で確認が必要
- 5: 電話番号、日時、氏名の復唱が安定

## 受付らしさ
- 1: 雑談寄りで一次受付にならない
- 3: 案内はできるが業務感が弱い
- 5: 受付業務として違和感が少ない

## 被せ耐性
- 1: ユーザーの割り込みで崩れる
- 3: たまに会話が乱れる
- 5: 割り込み後も自然に立て直せる

## 判定の見方
- `会話スタック比較` は自然さ、受付らしさ、被せ耐性を重く見る。
- `TTS/読み比較` は読み、復唱精度を重く見る。
- 精度寄り profile は速度だけで合否を決めない。

## 記録テンプレート
- provider
- scenario
- run id
- transcript
- expected text
- first reply after user ms
- barge-in recovery ms
- subjective score
- notes

## 注意
- Eleven の `eleven_v3_conversational` と `eleven_v3` は別物として扱う。
- Gemini Live の `minimal` と `low` は別 run にする。
- 電話回線劣化はこのラボの比較対象に入れない。
