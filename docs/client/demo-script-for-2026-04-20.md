# 2026-04-20 デモ台本

## 目的
- 公開情報への質問に AI が短く正確に答えられることを見せる
- そのまま routine 初診の予約候補提示から仮確保まで進められることを見せる
- urgent または人対応希望は即時引き継ぎになることを見せる

## 推奨構成
- 1本目: FAQ -> 予約
- 2本目: 引き継ぎ

理由:
- 今のルーティングでは「人に代わってほしい」「今日かなり痛い」などを早めに言うと、その時点で live transfer に寄る
- そのため、1本の通話で予約と引き継ぎを両方きれいに見せようとすると不安定になる
- 明日のデモは 2 本に分けた方が成功率が高い

## デモ前チェック
- 起動は必ず `npm run dev` または `npm run start` を使う
- `GET /api/appointment-tool/health` が `healthy` であることを確認する
- `browserReady=true`
- `pageReady=true`
- `sessionInitializing=false`
- realtime monitor が無効でも問題ない。後段確認は transcript と予約結果で見る

## デモ1: FAQ -> 予約

### ねらい
- 公開情報の質問に答えられる
- FAQ のあと自然に予約 intake に戻れる
- live 候補提示 -> 候補選択 -> 仮確保/確定の流れを見せられる

### この通話で言わないこと
- 今日中に診てほしい
- かなり痛い
- 腫れている
- 人に代わってほしい

### 話者台本
1. 発信者
```text
初めてなんですが、営業時間とお休み、それから場所だけ先に教えてください。
```

期待する流れ:
- 営業時間
- 休診
- アクセス
を短く返す

2. 発信者
```text
ありがとうございます。じゃあ初診の予約もお願いしたいです。右上の歯がしみるのと、クリーニングも相談したいです。
```

期待する流れ:
- routine 初診として intake に戻る

3. 発信者
```text
山田花子です。
```

4. 発信者
```text
090-1234-5678です。
```

5. 発信者
```text
はい、初めてです。
```

6. 発信者
```text
まだLINEはやっていません。
```

7. 発信者
```text
第一希望は10月20日の午前、第二希望は10月22日の午後でお願いします。
```

期待する流れ:
- live availability lookup が走る
- 最大 3 候補程度が返る
- 「現時点の候補」であり、選択後に再確認する旨が案内される

8. 発信者
```text
では一番上の候補でお願いします。
```

期待する流れ:
- live hold confirm が走る
- `confirmed` ならその場で確定
- `pending_finalize_post_call` なら通話後に最終確認と案内

9. 発信者
```text
ありがとうございます。
```

### 司会コメント例
```text
まずは営業時間や場所のような公開情報にその場で答えます。そのあと同じ通話の中で初診予約に移り、空き枠を確認し、候補を返し、選ばれた候補をその場で再確認します。
```

## デモ2: live transfer

### ねらい
- 緊急性または人対応希望のときは予約導線に乗せず、即時引き継ぎすることを見せる

### もっとも安定する台詞
1. 発信者
```text
すみません、今日かなり痛くて不安なので、受付の方に代わってもらえますか。
```

期待する流れ:
- その場で live transfer
- 追加の予約質問はしない

### 代替パターン
1. 発信者
```text
腫れもあって心配なので、人の方に代わってください。
```

### 司会コメント例
```text
緊急性がある内容や人対応の希望が出た場合は、予約候補の提示より先にスタッフへ引き継ぎます。ここは安全性を優先しています。
```

## 1本で見せたい場合の短縮版

### 使いどころ
- 時間が短く、どうしても 1 本で FAQ -> 予約 -> 引き継ぎまで触れたいときだけ使う

### 推奨台本
1. FAQ と予約候補提示までは `デモ1` と同じ
2. 候補提示後または候補選択後に発信者が以下を言う

```text
ありがとうございます。最後に人の方にも少し確認したいので、代わってください。
```

### 注意
- このやり方は 2 本構成より不安定
- 引き継ぎが先に強く出ると予約側の見せ場が短くなる
- 明日の本番では 2 本構成を優先する
