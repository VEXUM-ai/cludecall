# 先方シート抽出 Knowledge Pack

元ファイル: `【アポ関連】マニュアル.xlsx`

## 1. 方針
- シート本文をそのまま prompt に入れない。
- AI に渡すのは `患者向け案内` と `予約制約の要点` だけに絞る。
- 認証情報、内部 URL、個人LINE、グループLINE、担当者依存の細手順は除外する。

## 2. シート別の扱い

### `基本`
- 採用
  - 初診は検査中心、応急処置になる場合あり
  - 急患初診は待ち時間が長くなる可能性
  - ホワイトニングは機材1台で重複不可
  - インビザはスタート / IPR / スキャン / リテーナーでドクター必須
  - LINE問診未回答なら15分前来院
- 除外
  - 個人名メモ運用
  - アポツールへの細かいメモ書き指示

### `THP`
- 採用
  - THP事前検査 9,500円
  - 90分 / 3枠
  - 歯科衛生士対応、ドクター不在でも可
- 除外
  - 個人LINE報告手順
  - 本院ブロック調整の詳細

### `無料歯科検診`
- 採用
  - 無料なのは審査診断まで
  - 治療希望なし 30分 / 治療希望あり 60分
  - メニュー: 一般歯科検診 / 矯正相談 / インプラント相談 / 審美相談
  - 当日治療希望の有無で受付案内が変わる
- 除外
  - Gmail 運用
  - 診断表の内部回し方

### `インプラント`
- 採用
  - 詳細スケジュールは人確認前提
  - 鎮静や支払い方法確認が必要なケースあり
- 除外
  - 付箋、朝礼、グループLINE、外部業者連絡

### `代診・名前つけるアポ一覧`
- 採用
  - 一部メニューは担当者制、平日制約、重ね取り不可がある
  - これらは `doctor_required` や `manual_review` の根拠に使う
- 除外
  - 個人名一覧そのもの

### `紹介`
- 採用しない
  - 患者向け FAQ より内部事務手順の比重が高く、紹介状作成や外部病院予約の内部フローが中心

### `LINE`
- 採用
  - LINE問診回答済みかどうかで案内が変わる
- 除外
  - 配信運用の詳細

### `【～4月まで！】SAデンタル`
- 全面除外
  - ログイン URL
  - メールアドレス
  - パスワード

## 3. AI に渡す構造
- `clinicProfile`
- `faqEntries`
- `bookingRules`
- `escalationRules`
- `redactionLedger`

## 4. service_line への対応
- `general_initial`
  - 通常初診
- `emergency_initial`
  - 急患、激痛、当日対応相談
- `implant_consult`
  - インプラント相談
- `thp_pretest`
  - THP事前検査
- `free_screening`
  - 無料歯科検診
- `whitening`
  - ホワイトニング
- `invisalign`
  - インビザライン
- `other_manual_review`
  - 美容系、紹介、レーザー可否などの個別確認案件

## 5. アポツール設計への反映
- AI には「何を聞くか」と「何を案内できるか」だけを持たせる。
- 実際の予約投入に必要な payload は `AppointmentDraft` としてアプリ側で組み立てる。
- これにより、シートの巨大な文面を毎回 context に入れずに済む。
